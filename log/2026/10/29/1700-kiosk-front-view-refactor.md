# 自助交易终端正视图与电动投卡抽屉精准工业级重构

## 第一次操作摘要（17:18）
根据真实工程六视图图纸与局部特写红框指示，彻底重构武汉交投自助交易终端的正视图立面与投卡工位动力学结构：

1. **电动投卡抽屉区域范围精准纠偏（图 3 红框对齐）**：
   - 彻底剥离原先将“↓ 请投卡 ↓”大字标识误做成整体抽屉的错误逻辑；
   - 将“↓ 请投卡 ↓”文字与上方插槽标识恢复为**完全固定在机柜工位面板上**（`fixedSlotPanel` + `slotPlate`），抽屉运动时固定不动；
   - 将可前后电动伸缩的抽屉组件容器 `drawerGroup` 严格收敛至图 3 红框圈定区域：高度仅约 0.075m 的扁平长条，包含**左侧红色【故障/取消】按钮**、**中间浅蓝色【RFID 刷卡感应与受卡插口】**、**右侧黄色【求助/呼叫】按钮**；
   - 抽屉向前滑出 0.16m 时，托盘内部深凹受卡槽与绿色导向指示灯露出，供司机投卡，3 秒后自动平滑缩回，与机柜面板平整贴合。

## 第二次追加操作摘要（17:36，针对用户指正的 3 个问题精准修复）
1. **工位底板与底部颜色彻底纠正为工程中灰色（图 2 箭头指正）**：
   - 依照图 2 红色箭头标注的“灰色”，通过图像色相提取确认工位大底板标准工业冷灰（RGB: 69, 72, 76，Hex: `#45484c`）；
   - 更新材质为 `materials.fasciaGrey`（`#45484c`），左侧工位大底板覆盖上下工位及底部，下工位下方自然呈现平整的工程中灰色，彻底消除此前死黑的失真质感。
2. **彻底移除机柜左侧多余垂直灯带（图 3 红框指正）**：
   - 严格核实图纸发现：图纸正视图左侧边缘为干干净净的垂直灰面，**左侧根本没有垂直绿灯带**；
   - 彻底移除了原先错误生成的 `greenLeftStrip`，纠正工位底板左侧包裹，保持机柜左边缘利落整洁。
3. **彻底根除弧形灯带与背景的 Z-fighting 闪烁 Bug（图 4 红框指正）**：
   - **贴图杂质彻底清理**：分析出 `brand-text.png` 原图中左侧含有原图纸截断残留的绿色弧形噪点与黑边，且为 RGB 模式导致透明度失效；通过 Python 重绘生成纯透明背景的高保真文字与 Logo 贴图，将 `x < 22` 的残留杂质全部剔除；
   - **材质属性防穿透优化**：为 `brandBoardMesh` 设置 `transparent: true, depthWrite: false`，彻底消除 WebGL 深度缓冲区冲突（Z-Fighting）引发的闪烁现象；
   - **三维真实反 C 型平滑流线导光条**：使用 `THREE.CurvePath` + `THREE.TubeGeometry` 构建包含顶部水平段、右上圆角、纵向交界面主导光带、右下圆角、底部水平段的整体平滑实体导光管道，精确勾勒工位与橙色展板分界，光泽圆润且无任何重叠锯齿。
