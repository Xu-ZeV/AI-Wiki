# 极简编辑式产品界面

> [!info] Skill 元信息
> 原始名称：`minimalist-ui`  
> 原始标题：Premium Utilitarian Minimalism UI Architect  
> 功能分类：高级前端 UI 设计与重构  
> 原始文件：[SKILL.md](../../../raw/SkillHub/taste-skills/skills/minimalist-skill/SKILL.md)

## 中文含义与用途

中文含义：生成克制、清晰、偏文档和产品工具感的极简界面。  
核心用处：用暖色单色系、强文字层级、平面 bento 网格、低阴影和低饱和点缀，生成类似 Notion、Linear、现代知识工具的高级产品 UI。

## 适用场景

适合知识库、生产力工具、文档产品、B2B SaaS、仪表盘、设置页、编辑器和需要长期阅读或重复操作的界面。

## 关键能力

- 禁止通用字体、重阴影、渐变、霓虹、glassmorphism 和大面积高饱和色
- 建立暖色单色背景、轻边框和稀少点缀色
- 使用编辑式字体层级和清晰段落宽度
- 生成平面组件、克制图标、低强度微动效
- 避免营销式夸张文案和模板人名

## 使用边界与注意事项

- 不适合需要强烈视觉冲击、游戏化或重品牌表达的页面。
- 原始规则偏严格，落地时应结合业务品牌和已有设计系统调整。
- 如果用户要求强烈实验感，可考虑 industrial-brutalist-ui。

## 原始描述中文摘要

干净的编辑式界面 skill，强调暖色单色调、文字对比、平面 bento 网格和柔和淡彩，禁止渐变和重阴影。
