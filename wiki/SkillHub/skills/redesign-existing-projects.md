# 现有项目高级 UI 改造

> [!info] Skill 元信息
> 原始名称：`redesign-existing-projects`

## 中文含义与用途

中文含义：为已有网站或应用做高级视觉重设计。  
核心用处：先审计当前代码库和 UI，再基于现有框架定向修复字体、颜色、表面、布局、交互状态、内容和组件模式，而不是推倒重写。

## 适用场景

当用户已有项目并希望“变好看”“更高级”“更像真实产品”“去掉 AI 味”时使用。适合 React、Vue、Svelte、Tailwind、CSS Modules、vanilla CSS 等不同栈。

## 关键能力

- 扫描框架、样式系统和现有组件模式
- 识别默认字体、廉价渐变、弱层级、缺失状态和模板化布局
- 按优先级修复 typography、color、surface、layout、motion 和 iconography
- 保持功能不变，做渐进式视觉提升
- 避免从零重写造成回归风险

## 使用边界与注意事项

- 它适合已有项目，不是绿色地新建页面的默认首选。
- 审计结论应落到具体文件和组件，避免只给泛泛设计建议。
- 对复杂业务系统，优先保留可用性和信息密度，再提升视觉质感。

## 原始描述中文摘要

用于把现有网站和应用升级到更高级的视觉质量。它先审计当前设计，识别普通 AI 输出模式，再在不破坏功能的前提下应用高级设计标准。
