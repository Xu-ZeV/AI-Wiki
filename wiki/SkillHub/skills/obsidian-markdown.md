# Obsidian Markdown 笔记语法

> [!info] Skill 元信息
> 原始名称：`obsidian-markdown`

> 原始文件：[SKILL.md](../../../raw/SkillHub/obsidian-skills/skills/obsidian-markdown/SKILL.md)

## 用途

创建和编辑 Obsidian 风格 Markdown 笔记，覆盖 wikilink、嵌入、callout、frontmatter 属性、标签、注释、数学公式、Mermaid 和脚注。

## 适用场景

当任务涉及 Obsidian 中的 .md 笔记、双链、嵌入块、callout、属性、标签或笔记渲染时使用。

## 关键能力

- 规范生成 frontmatter 和正文结构
- 使用 `[[wikilink]]` 连接 vault 内笔记
- 用 `![[embed]]` 嵌入笔记、图片、PDF 或章节
- 编写 callout、标签、隐藏注释、公式和 Mermaid 图

## 使用边界与注意事项

- 内部笔记优先用 wikilink，外部链接使用标准 Markdown 链接。
- 生成后应关注 Obsidian 阅读视图的渲染效果。

## 原始描述摘要

Create and edit Obsidian Flavored Markdown with wikilinks, embeds, callouts, properties, and other Obsidian-specific syntax. Use when working with .md files in Obsidian, or when the user mentions wikilinks, callouts, frontmatter, tags, embeds, or Obsidian notes.
