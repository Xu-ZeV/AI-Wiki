# Skill 创建、优化与评估

> [!info] Skill 元信息
> 原始名称：`skill-creator`  
> 原始标题：Skill Creator  
> 功能分类：Skill 开发与验证  
> 原始文件：[SKILL.md](../../../raw/SkillHub/categories/skill-dev/skill-creator/SKILL.md)

## 用途

创建新 skill、修改已有 skill、优化触发描述，并通过 evals 和 benchmark 衡量 skill 表现。

## 适用场景

当用户要从零创建 skill、编辑或优化 skill、测试触发准确率、跑评估或分析性能方差时使用。

## 关键能力

- 设计 skill 结构和说明
- 优化 description 以提升触发准确率
- 编写和运行 evals
- 评估 skill 可靠性与改进空间

## 使用边界与注意事项

- 适合改进 SkillHub 本身。
- 完成后可用 impl-validator 做实现质量复查。

## 原始描述摘要

Create new skills, modify and improve existing skills, and measure skill performance. Use when users want to create a skill from scratch, edit, or optimize an existing skill, run evals to test a skill, benchmark skill performance with variance analysis, or optimize a skill's description for better triggering accuracy.
