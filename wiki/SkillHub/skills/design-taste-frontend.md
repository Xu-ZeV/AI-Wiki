# 高级前端设计品味

> [!info] Skill 元信息
> 原始名称：`design-taste-frontend`

> 功能分类：高级前端 UI 设计与重构  
> 原始文件：[SKILL.md](../../../raw/SkillHub/taste-skills/skills/taste-skill/SKILL.md)

## 中文含义与用途

中文含义：把 agent 变成更有设计品味的高级前端工程师。  
核心用处：为新建或改造的前端界面提供一套默认设计工程规则，约束布局、字体、颜色、间距、动效、响应式和依赖检查，减少普通 AI 页面常见的模板感。

## 适用场景

当用户要求构建网站、产品页、SaaS 界面、仪表盘、作品集或其他需要高完成度视觉质量的前端页面时使用。它适合作为 Taste Skill 系列的通用默认入口。

## 关键能力

- 使用设计变量控制布局变化、动效强度和信息密度
- 检查依赖、Tailwind 版本和 React/Next.js 组件边界
- 强制移动端稳定布局和合理响应式断点
- 避免常见 AI UI 痕迹，如廉价渐变、模板卡片、错误字体和松散间距
- 给出高端界面所需的字体、网格、动效和组件规则

## 使用边界与注意事项

- 它是设计和实现规则，不替代具体业务需求分析。
- 如果任务已有现成代码库，优先先读项目结构，再按现有技术栈落地。
- 如果只需要生成参考图，应改用 imagegen-frontend-web、imagegen-frontend-mobile 或 brandkit。
