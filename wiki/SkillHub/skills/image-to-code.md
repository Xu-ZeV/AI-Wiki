# 图片优先的网站设计到代码

> [!info] Skill 元信息

## 中文含义与用途

中文含义：先做设计图，再按图写代码的网站实现流程。  
核心用处：让 agent 在视觉重要的网页任务中先生成足够清晰、分区明确的参考图，逐项分析构图、字体、间距、颜色和组件，再实现尽量贴近参考图的前端。

## 适用场景

适合落地页、品牌官网、产品页、作品集、多区块营销页和任何“视觉质量比普通功能页面更重要”的网站任务。

## 关键能力

- 强制先生成设计图，再分析，再编码
- 按 section 生成足够数量的参考图，避免一张压缩大图塞满所有内容
- 生成新的细节图或分区图，而不是裁剪旧图凑数
- 深度分析图片中的布局、字体、色彩、动效暗示和组件系统
- 避免卡片套卡片、廉价 hero、重复左右布局和不可还原的图片设计

## 使用边界与注意事项

- 它依赖图像生成和视觉比对流程，不适合纯后端或无视觉要求的任务。
- 编码时仍要遵守当前项目技术栈和依赖限制。
- 如果只需要生成图像、不需要代码，可直接使用 imagegen-frontend-web。

## 原始描述中文摘要

面向 Codex 的网站 image-to-code skill。视觉重要任务必须先生成设计图、深入分析，再实现尽可能匹配的页面，并避免低质量图像压缩和偷懒式少量出图。
