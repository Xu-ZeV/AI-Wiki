# Wiki 动态仪表盘

> [!info] Skill 元信息
> 原始名称：`wiki-dashboard`  
> 原始标题：Wiki Dashboard — Dynamic Vault Views  
> 功能分类：可视化、仪表盘与导出  
> 原始文件：[SKILL.md](../../../raw/SkillHub/obsidian-wiki/skills/wiki-dashboard/SKILL.md)

## 用途

使用 Obsidian Bases 或 Dataview 创建可查询、自动更新的 vault dashboard 和内容索引视图。

## 适用场景

当用户要求创建 dashboard、表格展示所有 X、dynamic view、query vault、内容索引或结构化视图时使用。

## 关键能力

- 用 Bases 构建原生动态视图
- 用 Dataview 支持插件式查询
- 展示 concepts/entities/projects 等页面集合
- 创建表格、卡片或索引型 dashboard

## 使用边界与注意事项

- Bases 是 Obsidian 1.8+ 原生能力；Dataview 需要社区插件。
- 如果只需要 .base 语法细节，参考 obsidian-bases。

## 原始描述摘要

Create dynamic, queryable dashboard views of the Obsidian vault using Obsidian Bases or Dataview. Use this skill when the user says "create a dashboard", "vault dashboard", "show all X as a table", "dynamic view", "query my vault", "build a content index", "show me all concepts/entities/projects", or wants a structured, auto-updating view of their wiki content. Bases is native to Obsidian 1.8+ (no plugin needed). Dataview requires the community plugin.
