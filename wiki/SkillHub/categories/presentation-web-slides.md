# 演示文稿与网页幻灯片

面向演讲、分享、发布会和网页展示的演示文稿生成 skill。此分类强调 HTML 原生幻灯片、演讲者工具、视觉风格系统、浏览器交付和生成后的自动校验。

## Skill 列表

| Skill | 中文名 | 原始 Skill | 功能定位 |
| --- | --- | --- | --- |
| [[guizang-ppt-skill]] | 归藏网页 PPT 生成 | `guizang-ppt-skill` | 生成单文件横向翻页 HTML PPT，提供电子杂志与瑞士国际主义两套视觉系统，并集成演讲者视图、观众屏同步、讲稿备注和校验脚本。 |
| [[html-ppt]] | HTML PPT 工作室 | `html-ppt` | 以 36 套主题、15 套完整 deck、31 种布局、47 个动效和 Presenter Mode 生成专业静态 HTML 演示文稿。 |

## 使用建议

- 人文分享、行业观察和故事型表达优先选择 [[guizang-ppt-skill]] 的电子杂志风。
- 科技产品、数据汇报、工程分享和年度总结可选择 [[guizang-ppt-skill]] 的瑞士国际主义风，或使用 [[html-ppt]] 的 `swiss-grid`、`blueprint`、`tokyo-night` 等主题快速起步。
- 需要大量主题、布局、动效、showcase 或小红书图文模板时，优先选择 [[html-ppt]]。
- 需要多文件概览墙、自动导出 PDF、可编辑 PPTX 或把同一设计语言扩展到原型和动画时，可转用 [[huashu-design]]。
- 需要密集表格或多人实时协作编辑时，应改用专门的 PPTX 或在线协作工具。
