# Obsidian 基础能力与文件格式

面向 Obsidian 笔记、CLI、Bases 数据视图和 JSON Canvas 文件的基础操作能力。

## Skill 列表

| Skill | 中文名 | 原始 Skill | 功能定位 |
| --- | --- | --- | --- |
| [[obsidian-markdown]] | Obsidian Markdown 笔记语法 | `obsidian-markdown` | 创建和编辑 Obsidian 风格 Markdown 笔记，覆盖 wikilink、嵌入、callout、frontmatter 属性、标签、注释、数学公式、Mermaid 和脚注。 |
| [[obsidian-cli]] | Obsidian CLI 操作与插件调试 | `obsidian-cli` | 通过 obsidian CLI 与正在运行的 Obsidian vault 交互，读取、创建、搜索、追加、管理属性和任务，也支持插件或主题开发调试。 |
| [[obsidian-bases]] | Obsidian Bases 数据视图 | `obsidian-bases` | 创建和编辑 .base 文件，用 Obsidian Bases 构建类似数据库的笔记视图、筛选器、公式、汇总和多种展示方式。 |
| [[json-canvas]] | JSON Canvas 画布文件 | `json-canvas` | 创建和编辑 Obsidian JSON Canvas .canvas 文件，管理节点、边、分组、布局、颜色和连接关系。 |

## 使用建议

- 先用这些 skill 保证 Obsidian 文件格式正确，再交给导入、仪表盘或维护类 skill 扩展工作流。
- 修改 .canvas、.base 或 Obsidian Markdown 后，应优先做语法和引用完整性检查。
