# 概念索引

- [[wiki/concepts/agent-memory|Agent Memory]]：LangChain agent 保存短期线程状态和长期记忆的机制。
- [[wiki/concepts/context-engineering|Context Engineering]]：为 agent 动态提供正确模型上下文、工具上下文和生命周期上下文的工程实践。
- [[wiki/concepts/langchain-agent-harness|LangChain Agent Harness]]：LangChain v1 中围绕模型循环组织 prompt、tools、middleware 和状态的 agent 运行结构。
- [[wiki/concepts/llm-wiki|LLM Wiki]]：一种把原始资料编译成持久化 Markdown 知识库的知识管理模式。
- [[wiki/concepts/retrieval-augmented-generation|Retrieval-Augmented Generation]]：通过运行时检索外部知识增强 LLM 回答的 RAG 架构。
- [[wiki/concepts/structured-output|Structured Output]]：让 agent 按 schema 返回可校验结构化数据的机制。
- [[wiki/concepts/tool-calling|Tool Calling]]：让模型在推理过程中调用外部函数、API、检索器或业务动作的机制。
