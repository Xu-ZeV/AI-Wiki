# 幻灯片参考

使用 Chart.js 数据可视化、设计标记、响应式布局和文案公式进行战略性 HTML 演示设计。

## 用法

激活 `design` 技能并指定幻灯片任务，例如“创建一个融资演讲稿”。

## 知识库

|主题 |文件|目的|
|-------|------|---------|
|创作指南| `references/slides-create.md` |分步幻灯片创建工作流程 |
|布局模式| `references/slides-layout-patterns.md` |幻灯片布局模板和网格系统|
| HTML 模板 | `references/slides-html-template.md` |演示文稿的基本 HTML 结构 |
|文案| `references/slides-copywriting-formulas.md` | AIDA、PAS、FAB 用于幻灯片内容 |
|策略| `references/slides-strategies.md` |按演示类型划分的情境策略 |

## 何时使用

- 营销演示和宣传材料
- 具有 Chart.js 可视化效果的数据驱动幻灯片
- 具有布局模式的策略性幻灯片设计
- 文案优化的演示内容
- 投资者资料、销售演示、团队最新动态

## 主要特点

- **Chart.js 集成**：条形图、折线图、饼图、圆环图、雷达图
- **设计标记**：一致的间距、颜色、版式
- **响应式**：适用于桌面和移动设备
- **文案写作**：内置AIDA、PAS、FAB公式
- **布局模式**：英雄、分割、网格、比较、时间线

## 工作流程

1. 从用户请求中解析呈现类型
2.加载`references/slides-create.md`创建向导
3. 从`references/slides-layout-patterns.md`中选择布局图案
4.应用`references/slides-copywriting-formulas.md`中的文案公式
5.使用`references/slides-html-template.md`中的HTML模板
6.应用`references/slides-strategies.md`的策略
