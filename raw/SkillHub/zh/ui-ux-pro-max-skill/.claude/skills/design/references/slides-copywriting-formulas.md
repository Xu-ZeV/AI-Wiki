# 文案公式

25 个有说服力的幻灯片复制公式。

## 核心公式

### PAS（问题-搅动-解决方案）
**用途：**问题幻灯片、痛点
**组成部分：** 问题 → 搅动 → 解决方案
**模板：**“[痛点]？每个[时间范围]，[后果]。[解决方案]解决了这个问题。”

### AIDA（注意力-兴趣-欲望-行动）
**使用：** CTA，关闭幻灯片
**组成部分：** 注意力 → 兴趣 → 欲望 → 行动
**模板：**“[粗体声明]。[福利细节]。[社会证明]。[CTA]。”

### FAB（特性-优点-好处）
**用途：** 专题幻灯片、产品展示
**组成部分：** 特征 → 优势 → 效益
**模板：**“[功能]让您[优势]，因此您可以[受益]。”

### 不作为的成本
**用途：** 搅拌幻灯片，紧急
**组成部分：** 现状 → 损失 → 时间衰减
**模板：**“如果没有[解决方案]，您每个[时间范围]都会损失[金额]。”

### 桥接之前-之后
**用途：** 转型幻灯片、案例研究
**组件：** 之前 → 之后 → 桥
**模板：**“[之前的痛点]。[之后的期望状态]。[你的解决方案]就是桥梁。”

## 公式到幻灯片的映射

|幻灯片类型|初级配方|情感|
|------------|-----------------|---------|
|标题/挂钩 |阿依达，胡克|好奇心|
|问题 | PAS，搅拌|挫败感|
|成本/风险|不作为的成本|恐惧|
|解决方案 | FAB、BAB |希望|
|特点| FAB |信心|
|牵引|证明堆栈|信任|
|社会证明|感言 |信任|
|定价|价值堆栈|信心|
|美国消费者协会 |阿依达，紧急|紧急|

## 标题模式

### 能量词
- “停止[坏事]”
- “在[时间范围]内获得[期望的结果]”
- “[行动]的[形容词]方式”
- “为什么[受众]选择[产品]”
- “[数量]种[实现目标]的方法”

### 对比图案
- “[旧方式]已死。遇见[新方式]。”
- “不要[不良行为]。相反，[良好行为]。”
- “从[痛点]到[好处]。”

### 社会证明模式
- “[数量]+[用户/公司]信任[产品]”
- “加入[著名公司]和[著名公司]”
- “如[出版物]所示”
