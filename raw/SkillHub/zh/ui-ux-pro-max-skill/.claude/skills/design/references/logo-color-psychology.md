# 标志颜色心理学

## 原色含义

### 蓝色
- **心理学：** 信任、稳定、专业、冷静
- **行业：** 金融、医疗保健、科技、企业
- **十六进制示例：** 海军 #003366、皇家 #0055A4、天空 #0EA5E9
- **搭配：** 白色、金色、浅灰色

### 红色
- **心理学：** 能量、激情、紧迫感、兴奋
- **行业：** 食品、体育、娱乐、销售
- **十六进制示例：** Crimson #DC2626、Scarlet #EF4444、Burgundy #9F1239
- **配对：** 白色、黑色、金色
- **注意：**避免保健（血液内涵）

### 绿色
- **心理学：** 成长、自然、健康、可持续性
- **行业：** 生态、健康、有机、金融（增长）
- **十六进制示例：** Forest #228B22、Sage #2E8B57、Mint #10B981
- **配对：** 白色、棕色、蓝色

### 黄色/金色
- **心理学：** 乐观、温暖、奢华、关注
- **行业：** 食品、儿童、奢侈品（黄金）、能源
- **十六进制示例：** 金色 #D4AF37、琥珀色 #F59E0B、柠檬色 #FACC15
- **搭配：** 黑色、海军蓝、深棕色

### 紫色
- **心理学：**创造力、智慧、奢华、神秘
- **行业：** 美容、创意、精神、优质
- **十六进制示例：** Royal #7C3AED、Lavender #A78BFA、Deep #581C87
- **配对：** 金色、白色、粉色

### 橙色
- **心理：** 友善、精力充沛、自信、年轻
- **行业：** 食品、体育、娱乐、零售
- **十六进制示例：** 橘子 #F97316、珊瑚 #FB923C、烧焦 #EA580C
- **搭配：** 白色、海军蓝、深灰色

### 黑色
- **心理学：** 成熟、力量、优雅、权威
- **行业：** 奢侈品、时尚、科技、高端
- **配对：** 白色、金色、银色
- **注：** 用于高端定位

### 白色
- **心理学：** 纯粹、简单、干净、现代
- **使用：** 背景、负空间、对比度
- **搭配：** 任何颜色（通用中性色）

## 色彩和谐类型

### 单色
单色，带有色调/阴影。安全、有凝聚力。

### 补充
相反的颜色（蓝橙色）。对比度高，充满活力。

### 类似
相邻颜色（蓝色-青色-绿色）。和谐、自然。

### 三元组
三种均匀间隔的颜色。平衡、动态。

## 辅助功能注意事项

- 最小对比度：4.5:1 (WCAG AA)
- 避免只有红绿指示器
- 灰度测试清晰度
- 考虑色盲用户（约 8% 的男性）
