# CIP 可交付指南

## 核心身份

### 主要标志
- 矢量格式（SVG、AI、EPS）
- 明确的空间规则定义
- 可从网站图标扩展到广告牌

### 标志变体
- 水平、垂直、堆叠
- 仅图标/符号
- 单色版本（黑色、白色、反转）

## 文具套装

### 名片
- 标准：3.5x2 英寸/85x55 毫米
- 优质纸材（300-400gsm）
- 表面处理：哑光、局部 UV、箔、压花

### 信笺
- A4 或 Letter 尺寸
- 徽标/联系人的标题区域
- 数字版和印刷版

### 信封
- DL、C4、C5 尺寸
- 翻盖或正面带有徽标
- 返回地址样式

## 办公环境

### 接待处标牌
- 3D立体字母
- 背光 LED 选项
- 材质：亚克力、金属、木材

### 寻路系统
- 一致的图标系统
- 层次清晰
- ADA 合规性

### 墙图
- 使命/价值观显示
- 大型壁画
- 窗户磨砂

## 服装

### Polo 衫
- 刺绣优先
- 左胸部放置
- 优质面料（珠地棉）

### 制服
- 部门颜色编码
- 姓名徽章集成
- 安全要求（如果适用）

## 车辆品牌

### 汽车/轿车
- 门板品牌
- 部分或全包裹
- 联系信息可见

### 车队车辆
- 整个机队的设计保持一致
- 高可见度的联系方式
- 专业安装

## 数字资产

### 社交媒体
- 个人资料图片（图标版）
- 封面图片（特定于平台）
- 帖子模板

### 电子邮件签名
- HTML 响应式
- 最大 600 像素宽度
- 仅限必要联系

## 活动与促销

### 贸易展摊位
- 模块化设计
- 组装方便
- 关键消息可见

### 促销品
- 质量重于数量
- 有用的物品优先
- 品牌色彩突出
