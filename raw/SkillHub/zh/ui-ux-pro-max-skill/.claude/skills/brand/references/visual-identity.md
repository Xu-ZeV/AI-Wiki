# 视觉识别基础知识

## 核心视觉元素

### 标志
- **主要：** 完整徽标（水平/堆叠）
- **次要：** 缩写版本
- **图标/标记：** 仅符号
- **空白空间：** 徽标周围的最小填充
- **最小尺寸：**最小可读尺寸

### 调色板
```
Primary Colors (1-2)
├── Main brand color
└── Supporting primary

Secondary Colors (2-3)
├── Accent colors
└── Supporting visuals

Neutrals (3-4)
├── Text colors
├── Background colors
└── UI elements
```
