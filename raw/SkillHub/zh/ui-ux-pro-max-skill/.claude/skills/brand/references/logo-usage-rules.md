# 标志使用规则

在所有营销材料中正确实施徽标的指南。

## 标志变体

### 主要变体
|变体 |文件名 |使用案例|
|---------|-----------|----------|
|全卧式|徽标全水平。{ext} |网站标题、文档 |
|堆叠|徽标堆叠。{ext} |方形空间，社交化身|
|仅图标 |徽标图标。{ext} |网站图标、应用程序图标、小空间 |
|仅文字标记 |徽标文字标记。{ext} |当图标已经存在时 |

### 颜色变体
|变体 |使用案例|
|---------|----------|
| Full Color |默认为白色/浅色背景 |
|反转|在深色背景上 |
|单色深色|当颜色不可能时在浅色背景上|
|单色光|当颜色不可能时在深色背景上 |

## 清理空间

### 最小净空间
徽标周围的净空间应等于徽标标记（图标部分）的高度。

```
    ┌─────────────────────────────┐
    │           [x]               │
    │   ┌───────────────────┐     │
    │   │                   │     │
[x] │   │    [LOGO]         │ [x] │
    │   │                   │     │
    │   └───────────────────┘     │
    │           [x]               │
    └─────────────────────────────┘
```

其中 [x] = 徽标标记的高度

## 最小尺寸

### 数字
|格式|最小宽度|笔记|
|--------|---------------|-------|
|完整标志| 120 像素 |所有元素清晰易读 |
|仅图标 | 24 像素 |网站图标/小图标|
|仅图标 | 32 像素 |UI元素 |

### 打印
|格式|最小宽度|笔记|
|--------|---------------|-------|
|完整标志| 35毫米|名片、信笺|
|仅图标| 10毫米|小印刷项目 |

## 颜色使用

### 批准的背景
|背景|徽标版本 |
|------------|--------------|
|白色|全彩或深色单色 |
|浅灰色 (#F5F5F5+) |全彩或深色单色|
|品牌主|反转（白色）|
|深色（#333 或更暗）|反转（白色）|
|摄影 |确保足够的对比度|

### 颜色规则
1. 切勿在认可的调色板之外更改徽标颜色
2. 不要在标志上使用渐变
3. 不要对徽标元素应用透明度
4. 不要添加阴影或效果

## 错误用法

### 绝对不要做的事
- ❌ 拉伸或压缩徽标
- ❌ 旋转一定角度
- ❌添加阴影
- ❌应用渐变填充
- ❌ 使用未经批准的颜色
- ❌添加笔画或轮廓
- ❌ 放置在繁忙的背景上
- ❌裁剪任何部分
- ❌重新排列元素
- ❌添加附加元素

### 视觉示例
```
WRONG: Stretched      WRONG: Rotated       WRONG: Wrong color
┌──────────────┐      ┌────────┐          ┌────────┐
│   L O G O    │      │  /    │          │ LOGO   │ <- wrong color
└──────────────┘      │ /LOGO │          └────────┘
                      └───────/
```

## 联合品牌

### 合作伙伴徽标指南
1.视觉重量相等（高度相同）
2. 标志之间充分分离
3. 如果需要，使用分隔线
4. 两个标志均采用其认可的颜色
5. 净空间适用于两者

### 布局选项
```
Option A: Side by side with divider
[OUR LOGO] | [PARTNER LOGO]

Option B: Stacked
    [OUR LOGO]
        +
  [PARTNER LOGO]
```

## 标志审批流程

### 使用徽标之前
1.确认您拥有正确的版本
2.检查后台兼容性
3. 确保最小尺寸要求
4. 确认空闲空间分配
5. 根据这些准则进行审查

### 请求批准
For non-standard uses:
1. 提交显示建议用途的模型
2. 包括背景（媒介、受众）
3.等待品牌团队批准
4. 记录批准的例外情况
