# 品牌声音框架

## 声音与语气

**声音**=品牌的个性（一致）
**语气** = 语音如何适应上下文（变量）

示例：友好的品牌（声音）可能会在获胜公告中表示庆祝，但在支持响应（语气）中可能会表现出同理心。

## 声音维度

### 音谱
```
Formal ←――――――――――――――→ Casual
[Legal docs]     [Social media]
```

### 语言谱
```
Simple ←――――――――――――――→ Complex
[Consumer]       [Technical B2B]
```

### 性格谱
```
Serious ←――――――――――――――→ Playful
[Finance]        [Entertainment]
```

### 情绪谱
```
Reserved ←――――――――――――――→ Expressive
[Corporate]      [Lifestyle brand]
```

## 语音开发流程

### 第 1 步：定义人格特质
选择 3-5 个描述您品牌的特征：
- 自信，不傲慢
- 友善，但不专业
- 知识渊博，不居高临下
- 创新，不花哨
- 真实，不随意

### 第 2 步：创建语音图表

|特质 |描述 |做|不要 |
|-------|-------------|-----|-------|
| [特质] | 【意义】 | [示例] | [示例] |

### 步骤 3：情境适应

|背景 |音调转变|示例|
|---------|------------|---------|
|社交媒体|更休闲| “嘿！” |
|支持|更有同理心| “我们理解...” |
|法律 |更正式 | “根据……” |
|销售|更自信 | “你会看到结果...”|

## 语音测试

问这些问题：
1. 这听起来像我们的品牌吗？
2. 竞争对手会这么说吗？
3.它能引起观众的共鸣吗？
4. 是否符合我们的价值观？
