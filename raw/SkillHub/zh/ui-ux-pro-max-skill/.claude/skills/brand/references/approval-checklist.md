# 资产审批清单

用于在批准之前审查营销资产的综合清单。

## 快速回顾

在详细审查之前，请验证：
- [ ] 资产服务于既定目的
- [ ] 适合目标受众
- [ ] 没有明显的错误或问题
- [ ] 与活动目标保持一致

## 视觉元素

### 标志使用
- [ ] 上下文的正确徽标变体
- [ ] 保持适当的净空间
- [ ] 满足最小尺寸要求
- [ ] 仅认可的颜色
- [ ] 禁止未经授权的修改
- [ ] 适合背景

### 颜色合规性
- [ ] 仅使用品牌调色板颜色
- [ ] 适当的小学/中学比例 (60/30/10)
- [ ] 正确使用语义颜色
- [ ] 不引入非品牌颜色
- [ ] 所有元素保持一致

### 版式
- [ ] 始终使用品牌字体
- [ ] 应用正确的字体粗细
- [ ] 正确的类型层次结构
- [ ] 适合中号尺寸
- [ ] 行高足够
- [ ] 正文中没有孤儿/寡妇

### 图像
- [ ] 符合品牌摄影风格
- [ ] 适当的主题/内容
- [ ] 质量符合要求
- [ ] 获得适当许可/认可
- [ ] 针对预期用途进行了优化

## 辅助功能

### 视觉辅助功能
- [ ] 文本对比度 >= 4.5:1 (AA)
- [ ] 大文本对比度 >= 3:1
- [ ] 交互元素具有可见焦点
- [ ] 颜色并非含义的唯一指示
- [ ] 所有图像的替代文本

### 内容可访问性
- [ ] 清晰且可扫描的布局
- [ ] 可读字体大小
- [ ] 逻辑阅读顺序
- [ ] 有意义的标题结构
- [ ] 链接描述目的地

## 内容质量

### 复制评论
- [ ] 匹配品牌声音
- [ ] 适合上下文的语气
- [ ] 未使用禁止术语
- [ ] 价值主张清晰
- [ ] CTA 引人注目且清晰
- [ ] 校对错误

### 消息传递
- [ ] 与关键信息保持一致
- [ ] 突出显示差异化因素
- [ ] 相对于功能的优势
- [ ] 目标受众
- [ ] 没有冲突的主张

## 技术要求

### 文件规范
- [ ] 正确的文件格式
- [ ] 适当的分辨率
- [ ] 文件大小优化
- [ ] 正确的命名约定
- [ ] 包含元数据

## 法律与合规

### 知识产权
- [ ] 已获得许可的库存图片
- [ ] 音乐/音频已清除
- [ ] 没有商标侵权
- [ ] 用户内容已授权
- [ ] 需要时包含学分

### 监管
- [ ] 需要披露的信息
- [ ] 没有误导性声明
- [ ] 定价准确
- [ ] 需要链接的术语
- [ ] 符合隐私要求

## 常见问题和修复

|问题 |修复 |
|-------|-----|
|标志太小 |增加到最小尺寸|
|字体错误 |替换为品牌字体 |
|低对比度|调整颜色以实现可访问性 |
|非品牌颜色 |替换为调色板颜色 |
|图像模糊 |使用更高分辨率的源 |
|缺少替代文本 |添加描述性替代文本 |
|弱 CTA |强化行动文案|

## 自动化支持

`validate-asset.cjs` 脚本可以自动检查：
- 调色板合规性
- 最小尺寸
- 文件格式/大小
- 命名约定
- 基本元数据

运行：`node .claude/skills/brand/scripts/validate-asset.cjs <asset-path>`

## 档案

批准后：
1. 更新manifest.json中的资产状态
2.添加审批人和时间戳
3. Move previous versions to archive
4.更新活动跟踪
5.通知相关团队
