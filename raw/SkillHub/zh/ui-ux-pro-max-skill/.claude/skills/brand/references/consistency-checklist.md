# 品牌一致性检查表

## 视觉一致性

### 标志
- [ ] 使用正确的徽标版本
- [ ] 保持适当的净空间
- [ ] 仅认可的颜色
- [ ] 在所有尺寸下均清晰易读
- [ ] 禁止未经授权的修改

### 颜色
- [ ] 仅限品牌调色板颜色
- [ ] 一致的色彩应用
- [ ] 适当的对比度以实现可访问性
- [ ] 保持色彩比例

### 版式
- [ ] 使用的品牌字体
- [ ] 正确的重量/样式
- [ ] 正确的层次结构
- [ ] 一致的格式

### 图像
- [ ] 符合品牌风格
- [ ] 一致的编辑/过滤器
- [ ] 合适的科目
- [ ] 符合质量标准

## 语音一致性

### 语气
- [ ] 符合品牌个性
- [ ] 适合上下文
- [ ] 跨渠道一致
- [ ] 没有冲突的消息

### 语言
- [ ] 使用的品牌术语
- [ ] 大小写一致
- [ ] 正确的缩写
- [ ] 行话级别适当

### 消息传递
- [ ] 与关键信息保持一致
- [ ] 值属性清除
- [ ] 突出显示差异化因素
- [ ] CTA 一致

## 常见问题

|问题 |修复 |
|-------|-----|
|过时的标志|替换为当前版本 |
|非品牌颜色 |更新调色板 |
|字体错误 |替换为品牌字体 |
|声音不一致 |应用风格指南 |
|混合消息 |与框架对齐 |
