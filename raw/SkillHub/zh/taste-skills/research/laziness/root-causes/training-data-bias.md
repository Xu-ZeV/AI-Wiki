# 训练数据偏差

## 占位符传播

LLM通过模仿人类书写文本中的模式来学习。他们的训练数据很大一部分来自 Stack Overflow、GitHub 存储库和教程博客等来源。在这些来源中，人类开发者通常会编写缩写代码：

```python
def complex_logic():
    # implement auth here
    pass
```

该模型将这种模式内在化，并将占位符插入视为合法、专业的响应格式。它并不是故意隐瞒内容——它已经被训练成相信用注释截断代码是回答技术问题的正确方法。

## 模式强化

这种行为在多个数据源中得到强化：

- **代码教程**经常显示部分实现，并带有注释，指示学生应该在哪里完成逻辑
- **文档**经常使用带有省略号的缩写示例
- **论坛答案**定期提供骨架代码而不是完整的实现
- **博客文章**用“对于其余情况类似”截断重复的代码块

累积效应是，模型在适合完整代码生成的上下文中为截断标记分配高概率。

## 对输出质量的影响

当用户请求完整的实现时，模型面临着相互竞争的训练信号：产生完整输出的明确指令与产生简短的“教程式”响应的深层嵌入模式。如果没有积极的提示工程，教程式模式经常会获胜，因为它在训练分布中更为常见。
