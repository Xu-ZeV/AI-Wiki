# LLM 输出截断研究

对大型语言模型产生不完整输出的原因进行结构化分析，并记录恢复全保真生成的方法。所有研究结果均来自受控实验、已发表的研究和现场测试的工程实践。

## 目录结构

### 根本原因
分析导致生产型LLM产出截断的经济、架构和行为机制。

- [RLHF 和计算经济学](rlhf-and-compute.md) — 强化学习和成本优化如何造成系统性简洁偏差。
- [训练数据偏差](training-data-bias.md) — 人类编写的代码中的占位符模式如何传播到模型输出中。
- [认知捷径](cognitive-shortcuts.md) — 模型在复杂或冗长的任务上采取捷径的经验证据。
- [输出限制](output-limits.md) — 上下文窗口不对称和消费者层截断机制。

### 补救措施
用于覆盖默认截断行为的记录技术，从参数级修复到完整的架构解决方案。

- 【参数调优】(parameter-tuning.md)——温度、Top-p、双子座思维级别配置。
- [提示工程](prompt-engineering.md) — 结构提示技术：语法绑定、XML 框架和验证循环。
- [架构模式](architectural-patterns.md) — MCP 集成、延迟加载技能和开发者平台访问。
- [参考提示](reference-prompts.md) — 用于强制执行完整输出的即用型提示模板。

### 调查结果
- [实证结果](empirical-results.md) — 2025 年学术研究的对照实验数据。
- [参考文献](references.md) — 引用的研究和进一步阅读。
