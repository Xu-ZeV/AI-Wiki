# 设计系统：品味标准
**技能：**针法-设计-品味

---

## 配置 — 设置您的风格
在使用此设计系统之前调整这些刻度盘。它们控制输出的创意、密集度和动画程度。选择适合您的项目的级别。

|拨号 |水平|描述 |
|------|-------|-------------|
| **创造力** | `8` | `1` = 超简约、瑞士、静音、单色。 `5` = 平衡、干净但有个性。 `10` = 富有表现力、社论、大胆的排版实验、标题中的内嵌图像、强烈的不对称性。默认值：`8` |
| **密度** | `4` | `1` = 画廊式的、巨大的空白。 `5` = 平衡部分。 `10` = 驾驶舱密集、数据量大。默认值：`4` |
| **方差** | `8` | `1` = 可预测的对称网格。 `5` = 细微偏移。 `10` = 艺术混乱，没有两个部分是相同的。默认值：`8` |
| **运动意图** | `6` | `1` = 静态，无动画记录。 `5` = 微妙的悬停/进入提示。 `10` = 每个组件都注明了电影编排。默认值：`6` |

> **如何使用：** 更改上面的数字以匹配您的项目氛围。在 **创造力 1-3**，系统产生干净、安静、类似概念的界面。 **创造力 7-10** 可以期待内联图像排版、戏剧性的比例对比和强大的编辑布局。下面的其余规则适用于您选择的级别。

---

## 1.视觉主题和氛围
一个内敛、画廊式的界面，具有自信的不对称布局和流畅的弹簧物理运动。气氛冷静而温暖——就像一个光线充足的建筑工作室，每个元素都通过功能赢得自己的位置。密度是平衡的（第 4 级），方差较高（第 8 级）以防止对称无聊，运动是流畅的但绝不是戏剧性的（第 6 级）。总体印象：昂贵、有意、充满活力。

## 2. 调色板和角色
- **画布白色** (#F9FAFB) — 主要背景表面。暖中性，绝不临床的蓝白色
- **纯表面** (#FFFFFF) — 卡片和容器填充。与耳语阴影一起使用以提高高度
- **木炭墨水** (#18181B) — 主要文本。 Zinc-950 深度 — 绝不是纯黑色
- **Steel secondary** (#71717A) — 正文、描述、元数据。锌500温暖
- **Mated Slate** (#94A3B8) — 第三级文本、时间戳、禁用状态
- **耳语边框** (rgba(226,232,240,0.5)) — 卡片边框，结构 1px 线。半透明的深度
- **扩散阴影** (rgba(0,0,0,0.05)) — 卡高度。广泛传播，40 像素模糊，-15 像素偏移。从不严厉

### 口音选择（每个项目选择一个）
- **Emerald Signal** (#10B981) — 用于增长、成功、积极的数据仪表板
- **电蓝色** (#3B82F6) — 用于生产力、SaaS、开发者工具
- **Deep Rose** (#E11D48) — 适用于创意、编辑、时尚相关项目
- **琥珀色温暖** (#F59E0B) — 适用于社区、社交、暖色调产品

### 禁用颜色
- 紫色/紫色霓虹灯渐变——“AI Purple”美学
- 纯黑色 (#000000) — 始终为灰黑色或 Zinc-950
- 饱和度超过 80% 的过饱和口音
- 一个项目中混合暖/冷灰色系统

## 3. 版式规则
- **显示：** `Geist`、`Satoshi`、`Cabinet Grotesk` 或 `Outfit` — 轨道紧密 (`-0.025em`)、受控流体秤、重量驱动等级 (700–900)。没有尖叫。领先压缩（`1.1`）。强制替代方案——`Inter` 在高级环境中被禁止
- **琴体：** 相同系列，重量为 400 — 宽松引线 (`1.65`)，65 通道最大宽度，钢辅助色 (#71717A)
- **Mono:** `Geist Mono` 或 `JetBrains Mono` — 用于代码块、元数据、时间戳。当密度超过 7 级时，所有数字都会切换为等宽字体
- **比例：** 显示为 `clamp(2.25rem, 5vw, 3.75rem)`。主体位于 `1rem/1.125rem`。单声道元数据位于 `0.8125rem`

### 禁用字体
- `Inter` — 在高级/创意环境中到处禁止
- 通用衬线字体（`Times New Roman`、`Georgia`、`Garamond`、`Palatino`）- 禁止。如果编辑/创意需要衬线，请仅使用独特的现代衬线，例如 `Fraunces`、`Gambarino`、`Editorial New` 或 `Instrument Serif`。切勿使用默认的浏览器衬线堆栈。无论如何，衬线在仪表板或软件 UI 中始终被禁止

## 4. 组件样式
* **按钮：** 表面平坦，无外发光。主要：用白色文本强调填充。次要：幽灵/轮廓。活动状态：`-1px translateY` 或 `scale(0.98)` 用于触觉推动。悬停：微妙的背景变化，从不发光
* **卡片/容器：** 大圆角 (`2.5rem`)。纯白色填充。耳语边框（`1px`，半透明）。扩散阴影（`0 20px 40px -15px rgba(0,0,0,0.05)`）。内部填充 `2rem–2.5rem`。仅在标高传达层次结构时使用 - 高密度布局用 `border-top` 分隔线或负空间替换卡片
* **输入/表单：** 标签位于输入上方。辅助文本可选。下面的错误文本为 Deep Rose。调焦环采用强调色，`2px` 偏移。没有浮动标签。标签输入错误堆栈之间的标准 `0.5rem` 间隙
* **导航：** 光滑、粘性。图标在悬停时缩放（停靠放大可选）。桌面上没有汉堡包。干净的水平方向，间距宽敞
* **装载机：** 骨架闪光匹配精确的布局尺寸和圆角。在占位符形状之间移动光反射。切勿使用圆形旋转器
* **空状态：** 带有指导文本的组合插图或图标组合。绝不只是“未找到数据”
* **错误状态：** 内联、上下文。红色强调下划线或边框。明确的恢复动作

## 5.英雄部分
英雄是第一印象——它必须引人注目、有创意，而且绝不是通用的。
- **内联图像排版：**直接在标题中的单词或字母之间嵌入小型上下文照片或视觉效果。示例：“我们构建[双手打字的照片]数字[屏幕照片]产品”——图像在文字高度内嵌，呈圆形，充当单词之间的视觉标点符号。这是标志性的创意技巧
- **无重叠元素：** 文本不得与图像或其他文本重叠。每个元素都有自己清晰的空间区域。内容层没有 z 索引堆叠，图像上没有绝对定位的标题。始终保持干净的分离
- **无填充文本：** “滚动探索”、“向下滑动”、滚动箭头图标、弹跳 V 形和任何指导性 UI 镶边均被禁止。用户知道如何滚动。让内容自然地吸引他们
- **不对称结构：** 在此差异级别禁止居中英雄布局。使用分屏 (50/50)、左对齐文本/右视觉或带有大空白区域的不对称空白
- **CTA 限制：** 最多一个主 CTA 按钮。没有辅助的“了解更多”链接。标题下方没有多余的微文案

## 6. 布局原则
- **网格优先：** CSS 网格适用于所有结构布局。切勿使用 Flexbox 百分比数学（`calc(33% - 1rem)` 已被禁止）
- **无重叠：** 元素绝不能相互重叠。没有绝对定位的图层将内容堆叠在内容上。每个元素都占据自己的网格单元或流位置。干净、独立的空间区域
- **功能部分：** “连续 3 张相同的牌”模式已被禁止。使用 2 列之字形、不对称便当网格 (2fr 1fr 1fr) 或水平滚动画廊
- **收容：** `max-width: 1400px` 内的所有内容，居中。宽大的水平填充（`1rem` 移动设备、`2rem` 平板电脑、`4rem` 桌面设备）
- **全高：** 使用 `min-height: 100dvh` — 绝不使用 `height: 100vh`（iOS Safari 地址栏跳转）
- **Bento 架构：** 对于特征网格，使用第 1 行：3 列 |第 2 行：2 列（70/30 分割）。每个图块都包含一个永久的微动画

## 7. 响应规则
每个屏幕都必须在所有视口中完美运行。 **响应式不是可选的——这是一项硬性要求。每个元素都必须在 375 像素、768 像素和 1440 像素下进行测试。**
- **移动优先折叠（< 768px）：** 所有多列布局都折叠为严格的单列。 `width: 100%`、`padding: 1rem`、`gap: 1.5rem`。无一例外
- **无水平滚动：** 移动设备上的水平溢出是一个严重的故障。所有元素都必须适合视口宽度。如果任何元素导致水平滚动，则设计被破坏
- **版式缩放：** 标题通过 `clamp()` 优雅地缩小。正文至少保持为 `1rem`。切勿将主体缩小到 `14px` 以下。标题必须在 375 像素屏幕上保持可读性
- **触摸目标：** 所有交互元素最小 `44px` 点击目标。可点击项目之间的间距足够大。按钮在移动设备上必须为全角
- **图像行为：** 英雄和内联图像按比例缩放。内联排版图像（单词之间的照片）在移动设备上堆叠在标题下方，而不是内联
- **导航：** 桌面水平导航折叠为干净的移动菜单（滑入式或全屏覆盖）。没有没有标签的小汉堡图标
- **卡片和网格：** Bento 网格和不对称布局恢复为全宽的堆叠单列卡片。保持内部填充（`1rem`）
- **间距一致性：** 垂直部分间隙在移动设备上按比例减少 (`clamp(3rem, 8vw, 6rem)`)。绝不拥挤，也绝不过于通风
- **测试视口：** 设计必须在以下位置验证：`375px` (iPhone SE)、`390px` (iPhone 14)、`768px` (iPad)、`1024px`（小型笔记本电脑）、`1440px`（台式机）

## 8. 运动和交互（代码阶段意图）
> **注意：** Stitch 生成静态屏幕 - 它不会产生动画。本节记录了**预期的运动行为**，以便编码代理（反重力、光标等）在将导出的设计构建到实时产品中时准确地知道如何实现动画。

- **物理引擎：** 仅基于 Spring。 `stiffness: 100, damping: 20`。任何地方都没有线性缓动。所有互动元素都具有优质、厚重的感觉
- **永久微循环：** 每个活动仪表板组件都有无限循环状态 - 状态点上的脉冲、搜索栏上的打字机、功能图标上的浮动、加载状态上的闪烁
- **交错编排：** 列表和网格安装具有级联延迟 (`animation-delay: calc(var(--index) * 100ms)`)。瀑布显露，绝不瞬间登上
- **布局转换：** 通过共享元素 ID 平滑地重新排序。物品通过物理交换位置，模拟实时智能
- **硬件规则：** 仅制作 `transform` 和 `opacity` 的动画。绝不是 `top`、`left`、`width`、`height`。仅固定、pointer-events-none 伪元素上的颗粒/噪声过滤器
- **性能：** CPU 密集型永久动画隔离在微观叶子组件中。永远不要触发父级重新渲染。目标最低 60 fps

## 9. 反模式（禁止）
- 没有表情符号 - UI、代码或替代文本中的任何位置
- 无 `Inter` 字体 — 使用 `Geist`、`Outfit`、`Cabinet Grotesk`、`Satoshi`
- 没有通用衬线字体（`Times New Roman`、`Georgia`、`Garamond`） - 如果需要衬线，请仅使用独特的现代衬线字体（`Fraunces`、`Instrument Serif`）
- 无纯黑色 (`#000000`) — 仅 Off-Black 或 Zinc-950
- 没有霓虹灯外发光或默认的盒子阴影发光
- 强调色的饱和度不得超过 80%
- 大标题上没有过多的渐变文本
- 没有自定义鼠标光标
- 无重叠元素 - 文本永远不会与图像或其他内容重叠。始终保持干净的空间分隔
- 没有 3 列相同的功能卡片布局
- 没有居中的英雄部分（在此差异级别）
- 没有填充 UI 文本：“滚动探索”、“向下滑动”、“在下面发现更多内容”、滚动箭头、弹跳 V 形符号 — 全部禁止
- 无通用名称：“John Doe”、“Sarah Chan”、“Acme”、“Nexus”、“SmartFlow”
- 没有假整数：`99.99%`、`50%`、`1234567` — 使用有机数据：`47.2%`、`+1 (312) 847-1928`
- 没有人工智能文案陈词滥调：“提升”、“无缝”、“释放”、“下一代”、“革命化”
- 没有损坏的 Unsplash 链接 — 使用 `picsum.photos/seed/{id}/800/600` 或 SVG UI Avatars
- 无通用 `shadcn/ui` 默认值 — 自定义半径、颜色、阴影以匹配此系统
- 没有 `z-index` 垃圾邮件 - 仅用于导航栏、模态、覆盖层上下文
- 没有 `h-screen` — 始终为 `min-h-[100dvh]`
- 无圆形加载旋转器 - 仅骨架闪光
