# 技能：工业野蛮主义和战术遥测UI

## 1. 技能元
**名称：**工业野蛮主义和战术遥测接口工程
**描述：** 精通网页界面设计，综合了中世纪瑞士印刷设计、工业制造手册和复古未来航空航天/军事终端界面。这一学科需要绝对掌握严格的模块化网格、极端的印刷比例对比度、纯粹实用的调色板以及模拟退化的程序模拟（半色调、CRT 扫描线、位图抖动）。其目标是构建能够展现原始功能、机械精度和高数据密度的数字环境，并有意抛弃传统的消费者 UI 模式。

## 2. 视觉原型
该设计系统通过合并两种不同但高度兼容的视觉范例来运行。 **每个项目选择一个并致力于它。请勿在同一界面内交替或混合两种模式。**

### 2.1 瑞士工业印刷
源自 20 世纪 60 年代的企业形象系统和重型机械蓝图。
* **特性：** 高对比度光模式（新闻纸/灰白色基材）。依赖单一的、厚重的无衬线字体。由可见的分界线勾勒出严酷的结构网格。积极、不对称地使用负空间，中间点缀着超大、令人眼花缭乱的数字或字母。大量使用原色红色作为警报/强调色。

### 2.2 战术遥测和CRT终端
源自机密军事数据库、传统大型机和航空航天平视显示器 (HUD)。
* **特点：** 黑暗模式独占。高密度表格数据呈现。等宽字体的绝对统治地位。集成技术框架设备（ASCII 括号、十字准线）。模拟硬件限制的应用（荧光粉发光、扫描线、低位深度渲染）。

## 3. 版式架构
版式是主要的结构和装饰基础设施。图像是次要的。该系统要求在规模、重量和间距方面有极大的变化。

### 3.1 宏观排版（结构标题）
* **分类：** 新怪诞/重无衬线。
* **最佳网页字体：** Neue Haas Grotesk（黑色）、Inter（超粗体/黑色）、Archivo Black、Roboto Flex（重型）、Monument Extended。
* **实现参数：**
    * **规模：** 使用流体排版大规模部署（例如，`clamp(4rem, 10vw, 15rem)`）。
    * **跟踪（字母间距）：** 极其紧密，通常为负值（`-0.03em` 到 `-0.06em`），迫使字形形成坚固的结构块。
    * **行距（行高）：** 高度压缩（`0.85` 到 `0.95`）。
    * **外壳：** 仅采用大写字母以体现结构影响。

### 3.2 微型排版（数据和遥测）
* **分类：** 等宽字体 / Technical Sans。
* **最佳 Web 字体：** JetBrains Mono、IBM Plex Mono、Space Mono、VT323、Courier Prime。
* **实现参数：**
    * **规模：** 固定和小型（`10px` 至 `14px` / `0.7rem` 至 `0.875rem`）。
    * **跟踪：** 慷慨（`0.05em` 到 `0.1em`）来模拟机械打字机间距或终端矩阵。
    * **领先：** 标准到紧（`1.2` 到 `1.4`）。
    * **大小写：** 完全大写。用于所有元数据、导航、单元 ID 和坐标。

### 3.3 纹理对比（艺术破坏）
* **分类：** 高对比度衬线。
* **最佳网页字体：** Playfair Display、EB Garamond、Times New Roman。
* **实现参数：** 极其谨慎地使用。必须进行大量的后处理（半色调滤镜、1 位抖动），以降低矢量的完美度并与干净的无衬线字体形成纹理并置。

## 4. 颜色系统
色彩架构毫不妥协。严格禁止使用渐变、柔和阴影和现代半透明度。颜色模拟物理媒体或原始emits显示器。

**关键：每个项目选择一种基材调色板并一致使用。切勿在同一界面内混合浅色和深色基材。**

### 如果瑞士工业印刷（浅色）：
* **背景：** `#F4F4F0` 或 `#EAE8E3`（哑光、未漂白的文档纸）。
* **前景：** `#050505` 至 `#111111`（碳墨水）。
* **强调：** `#E61919` 或 `#FF2A2A`（航空/危险红色）。这是唯一的强调色。用于删除线、粗结构分界线或重要数据突出显示。

### 如果战术遥测（黑暗）：
* **背景：** `#0A0A0A` 或 `#121212`（停用的 CRT。避免纯 `#000000`）。
* **前景：** `#EAEAEA`（白色荧光粉）。这是主要文本颜色。
* **强调：** `#E61919` 或 `#FF2A2A`（航空/危险红色）。同样的红色，同样的规则。
* **绿色终端 (`#4AF626`)：** 可选。仅用于单个特定 UI 元素（例如，一个状态指示器或一个数据读数）——切勿用作一般文本颜色。如果它没有明确的目的，就完全忽略它。

## 5.布局与空间工程
布局必须看起来经过数学设计。它拒绝传统的网络填充，有利于可见的分隔。

* **蓝图网格：** 严格遵守 CSS 网格架构。元素不浮动；它们精确地固定在网格轨道和交叉口上。
* **可见的分区：** 广泛利用实体边界（`1px` 或 `2px solid`）来描绘不同的信息区域。水平规则（`<hr>`）经常跨越整个集装箱宽度以隔离操作单元。
* **双峰密度：** 布局在极端数据密度（紧密包装的等宽元数据聚集在一起）和计算出的负空间框架宏观排版之间摇摆。
* **几何形状：** `border-radius` 的绝对拒绝。所有拐角必须精确为 90 度，以增强机械刚性。

## 6. UI 组件和符号系统
标准 Web UI 惯例被实用的工业图形元素所取代。

* **语法修饰：** 利用 ASCII 字符来构建数据点。
    * *装帧：* `[ DELIVERY SYSTEMS ]`、`< RE-IND >`
* *方向：* `>>>`、`///`、`\\\\`
* **工业标记：** 显着整合注册 (`®`)、版权 (`©`) 和商标 (`™`) 符号，充当结构几何元素而不是法律文本。
* **技术资产：** 在网格交叉点处集成十字准线 (`+`)、重复垂直线（条形码）、粗水平警告条纹和随机字符串数据（例如，`REV 2.6`、`UNIT / D-01`）以模拟主动机械过程。

## 7. 纹理和后处理效果
为了防止设计看起来纯数字化，通过 CSS 和 SVG 滤波器将模拟模拟降级设计到前端。

* **半色调和 1 位抖动：** 将连续色调图像或大衬线字体转换为点阵图案。通过预处理或 CSS `mix-blend-mode: multiply` 叠加与 SVG 径向点图案相结合来实现。
* **CRT 扫描线：** 对于终端接口，将 `repeating-linear-gradient` 应用于背景以模拟水平电子束扫描（例如，`repeating-linear-gradient(0deg, transparent, transparent 2px, rgba(0,0,0,0.1) 2px, rgba(0,0,0,0.1) 4px)`）。
* **机械噪声：** 应用于 DOM 根的全局、低不透明度 SVG 静态/噪声过滤器，以在暗模式和亮模式下引入统一的物理颗粒。

## 8. Web 工程指令
1. **网格确定性：** 利用具有对比父/子背景颜色的 `display: grid; gap: 1px;` 来生成数学上完美的、极细的分割线，而无需复杂的边框声明。
2. **语义刚性：** 使用精确的语义标签（`<data>`、`<samp>`、`<kbd>`、`<output>`、`<dl>`）构建DOM，准确反映遥测的技术本质。
3. **版式限制：** 实现专门用于宏版式的 CSS `clamp()` 功能，以确保大量文本积极缩放，同时保持跨视口的结构完整性。
