> **需要额外的上下文**：性能限制。

添加传达状态、提供反馈并阐明层次结构的动作。剪切仅用于装饰的动作。动画疲劳是一种真实的成本；将预算花在需要的时刻。

---

## 注册

品牌：动作是声音的一部分；一个经过精心排练的入口胜过零散的微互动。饱和的人工智能默认是在每个滚动部分上淡入淡出显示；这是一个讲述，而不是一个编排。将滚动触发的动作保留在值得的时刻。

产品：大多数转换为 150–250 毫秒。运动传达状态：反馈、显示、加载、视图之间的转换。无页面加载编排；用户正在执行任务并且不会等待它。

---

## 评估动画机会

分析运动可以在哪些方面改善体验：

1. **识别静态区域**：
   - **缺少反馈**：没有视觉确认的操作（按钮点击、表单提交等）
   - **不和谐的转换**：感觉突然的即时状态变化（显示/隐藏、页面加载、路线变化）
   - **关系不清晰**：空间或层次关系不明显
   - **缺乏乐趣**：功能性但无乐趣的互动
   - **错过指导**：引导注意力或解释行为的机会

2. **理解上下文**：
   - 性格如何？ （俏皮与严肃，精力充沛与冷静）
   - 绩效预算是多少？ （移动优先？复杂页面？）
   - 观众是谁？ （对运动敏感的用户？想要速度的高级用户？）
   - 什么最重要？ （一个英雄动画与许多微交互？）

如果代码库中的任何内容不清楚，请停止并使用 Codex 的结构化用户输入/问题工具（如果可用）；如果无法推断，请直接在聊天中询问以澄清您无法推断的内容。

**重要**：尊重 `prefers-reduced-motion`。始终为需要的用户提供非动画替代品。

## 规划动画策略

创建有目的的动画计划：

- **英雄时刻**：ONE 标志性动画是什么？ （页面加载？英雄部分？关键交互？）
- **反馈层**：哪些交互需要确认？
- **过渡层**：哪些状态变化需要平滑？
- **愉悦层**：哪里可以给我们带来惊喜和愉悦？

**重要**：一种精心策划的体验胜过到处都是分散的动画。专注于高影响力的时刻。

## 实现动画

在这些类别中系统地添加运动：

### 入口动画
- **英雄部分**：主要内容的戏剧性入口（比例、视差或创意效果）
- **模态/抽屉入口**：平滑滑动+淡入淡出、背景淡入淡出、焦点管理
- **列表节奏**：兄弟姐妹交错对于网格中的卡片或列表项出现是合法的。整个部分的滚动淡入淡出不是列表，也不合法。总交错时间上限：10 个项目，每个项目 50 毫秒 = 总计 500 毫秒。对于更多项目，请减少每个项目的延迟或限制交错计数。

  使用 CSS 自定义属性实现干净的交错：每个项目上的 `animation-delay: calc(var(--i, 0) * 50ms)` 和 `style="--i: 0"`、`style="--i: 1"` 等。

### 微交互
- **按钮反馈**：
  - 悬停：细微比例 (1.02-1.05)、颜色偏移、阴影增加
  - 单击：快速缩小然后放大（0.95 → 1），波纹效果
  - 加载：旋转或脉冲状态
- **形成互动**：
  - 输入焦点：边框颜色过渡、轻微缩放或发光
  - 验证：错误时摇动、成功时勾选标记、平滑的颜色过渡
- **切换开关**：平滑滑动+颜色过渡（200-300ms）
- **复选框/单选**：复选标记动画、波纹效果
- **喜欢/最喜欢**：缩放+旋转、粒子效果、颜色过渡

### 状态转换
- **显示/隐藏**：淡入淡出+滑动（非即时），适当的时机（200-300ms）
- **展开/折叠**：带有溢出处理的高度过渡、图标旋转
- **加载状态**：骨架屏幕淡入淡出、旋转动画、进度条
- **成功/错误**：颜色过渡、图标动画、温和的刻度脉冲
- **启用/禁用**：不透明度过渡、光标更改

### 导航和流程
- **页面转换**：路线之间的交叉淡入淡出，共享元素转换
- **选项卡切换**：滑动指示器、内容淡出/滑动
- **轮播/滑块**：平滑变换、捕捉点、动量
- **滚动效果**：视差层、状态更改的粘性标题、滚动进度指示器

### 反馈与指导
- **悬停提示**：工具提示淡入、光标变化、元素突出显示
- **拖放**：提升效果（阴影+缩放）、放置区域高光、平滑重新定位
- **复制/粘贴**：粘贴时短暂突出显示，“已复制”确认
- **焦点流程**：突出显示表单或工作流程的路径

### 欢乐时刻
- **空状态**：插图上微妙的浮动动画
- **已完成的动作**：五彩纸屑、复选标记蓬勃发展、成功庆祝
- **复活节彩蛋**：隐藏的互动等待发现
- **情境动画**：天气效果、时间主题、季节风格

## 技术实现

对每个动画使用适当的技术：

### 计时和缓动

**持续时间：100/300/500 规则。** 对于“感觉正确”来说，时机比宽松更重要：

|持续时间 |使用案例|示例 |
|----------|----------|----------|
| **100–150ms** |即时反馈 |按钮按下、切换、颜色变化 |
| **200–300ms** |状态变化|菜单打开、工具提示、悬停状态 |
| **300–500ms** |布局变更 |手风琴、莫代尔、抽屉|
| **500–800ms** |入口动画|页面加载，英雄揭晓 |

**缓动曲线（使用这些，而不是 CSS 默认值）：**
```css
/* Recommended: natural deceleration */
--ease-out-quart: cubic-bezier(0.25, 1, 0.5, 1);    /* Smooth */
--ease-out-quint: cubic-bezier(0.22, 1, 0.36, 1);   /* Slightly snappier */
--ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);     /* Confident, decisive */

/* AVOID: feel dated and tacky */
/* bounce: cubic-bezier(0.34, 1.56, 0.64, 1); */
/* elastic: cubic-bezier(0.68, -0.6, 0.32, 1.6); */
```

**退出动画比进入快。** 使用大约 75% 的进入持续时间。

### CSS 动画
```css
/* Prefer for simple, declarative animations */
- transitions for state changes
- @keyframes for complex sequences
- transform and opacity for reliable movement
- blur, filters, masks, clip paths, shadows, and color shifts for premium atmospheric effects when verified smooth
```

### JavaScript 动画
```javascript
/* Use for complex, interactive animations */
- Web Animations API for programmatic control
- Framer Motion for React
- GSAP for complex sequences
```

### 运动材料

变换和不透明度是可靠的默认值，而不是整个调色板。高级界面通常需要大气属性。将材料与效果相匹配：

- **变换/不透明度**：移动、按下反馈、简单显示、列表编排
- **模糊/滤镜/背景滤镜**：焦点拉动、深度、玻璃或镜头效果、柔化入口
- **剪辑路径/蒙版**：擦拭、显示、编辑裁剪、类似产品的过渡
- **阴影/辉光/滤色镜**：能量、可供性、焦点、温暖、活跃状态
- **网格模板行或 FLIP 式转换**：扩展和回流布局，无需直接动画 `height`

硬性规则不是“仅变换和不透明度”。它是：避免随意动画布局驱动属性（`width`、`height`、`top`、`left`、边距），将昂贵的效果限制在小或孤立的区域，并验证浏览器中目标视口的平滑度。

### 性能
- **布局安全**：避免布局驱动属性的随意动画（`width`、`height`、`top`、`left`、边距）
- **will-change**：仅为已知的昂贵动画少量添加（例如在 `:hover` 或 `.animating` 类上），切勿抢占整个页面
- **滚动触发器**：使用 Intersection Observer 而不是滚动事件监听器；动画触发一次后取消观察
- **绑定昂贵的效果**：保持模糊/滤镜/阴影区域较小或孤立，在适当的情况下使用 `contain`
- **监控 FPS**：确保目标设备上的 60fps

### 感知性能

没有人关心您的网站*有多快*，只关心它感觉有多快。 80 毫秒阈值：任何低于 80 毫秒的事情都会感觉即时，因为我们的大脑会缓冲感官输入这么长时间以同步感知。以此为目标进行微交互。

- **抢先启动**：加载时立即开始转换（iOS 应用程序缩放、骨架 UI）。用户感知到工作正在发生。
- **早期完成**：渐进式显示内容，无需等待所有内容（渐进式图像、流式 HTML、骨架淡入）。
- **乐观的UI**：立即更新界面，优雅地处理故障。用于低风险操作（点赞、关注）。避免用于付款或破坏性操作。
- **缓和会影响感知的持续时间**：缓入（加速完成）使任务感觉更短，因为峰终效应对最后时刻的权重很大。进入时的缓出感觉令人满意。
- **注意**：太快的响应会降低复杂操作（搜索、分析）的感知价值。有时，短暂的延迟表明“真正的工作”正在发生。

### 辅助功能
```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```

**从不**：
- 使用弹跳或弹性缓动曲线；他们感觉过时并引起人们对动画本身的关注
- 当变换、翻转或基于网格的技术起作用时，随意动画布局属性（`width`、`height`、`top`、`left`、边距）
- 使用超过 500 毫秒的持续时间进行反馈（感觉很滞后）
- 没有目的的动画（每个动画都需要一个理由）
- 忽略 `prefers-reduced-motion`（这是可访问性违规）
- 一切都动画化（动画疲劳让界面感觉疲惫不堪）
- 除非故意，否则在动画期间阻止交互

## 验证质量

彻底测试动画：

- **60fps 流畅**：目标设备上无卡顿
- **感觉自然**：缓和曲线感觉有机，而不是机器人
- **适当的时机**：不太快（刺耳）或太慢（滞后）
- **减少运动效果**：适当禁用或简化动画
- **不阻塞**：用户可以在动画期间/之后进行交互
- **增加价值**：使界面更清晰或更令人愉快

当运动澄清状态而不是装饰它时，将其移交给 `$impeccable polish` 进行最终传递。
