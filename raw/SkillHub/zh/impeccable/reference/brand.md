# 品牌注册

当设计就是产品时：品牌网站、登陆页面、营销界面、活动页面、作品集、长篇内容、关于页面。可交付成果就是设计本身；访客的印象就是所形成的东西。

登记范围涵盖各个流派。科技品牌（Stripe、Linear、Vercel）。奢侈品牌（酒店、时装屋）。消费品（餐厅、旅游网站、CPG 包装页面）。一个创意工作室、一个代理机构组合、一个乐队的专辑页面。他们都有共同的立场（*沟通，而不是交易*），但在审美上却存在巨大差异。不要将它们折叠成单一的外观。

## 品牌倾斜度测试

如果有人看到这个并毫不犹豫地说“人工智能做到了”，那么它就失败了。酒吧是独特的；访客应该问“这是怎么制作的？”，而不是“哪个人工智能制作了这个？”

品牌不是一个中立的寄存器。人工智能生成的登陆页面已经充斥互联网，平均水平已无法找到。现在，无意识的克制被认为是平庸的，而不是精致的。品牌表面需要视角、特定受众、愿意冒陌生的风险。要么做大，要么回家。

**第二个斜坡测试：美学车道。** 在采取行动之前，请命名参考。克林姆风格的样本页是单行；最小条纹是另一个；液体-死亡-酸-极繁主义是另一个。不要在非社论的简报中陷入社论杂志的美学。带有鸬鹚斜体首字下沉的徒步旅行品牌在寄存器中的寄存器错误。

然后是逆向测试：用一句话描述您将要构建的产品，就像竞争对手描述他们的产品一样。如果该句子适合类别中的模式着陆页，请重新启动。

## 版式

### 字体选择程序

每个项目。切勿跳过。

1. 阅读简介。写下三个具体的品牌声音词。不是“现代”或“优雅”，而是“热情、机械和固执己见”或“冷静、临床和谨慎”。物理对象词。
2. 列出您本能地会使用的三种字体。如果有出现在下面的反射拒绝列表中，则拒绝它们；它们是训练数据默认值，并且创造了单一文化。
3. 浏览真实的目录（Google Fonts、Pangram Pangram、Future Fonts、Adobe Fonts、ABC Dinamo、Klim、Velvetyne），记住这三个单词。找到作为“物理对象”的品牌字体：博物馆标题、1970 年代的终端手册、织物标签、廉价新闻纸儿童读物、音乐会海报、中世纪小餐馆的收据。拒绝第一个“看起来有设计感”的东西。
4. 交叉检查。 “优雅”不一定是衬线体。 “技术”不一定是无意义的。 “温暖”不是弗朗西斯。如果最终的选择与最初的反应一致，则重新开始。

### 反射拒绝列表

训练数据默认值。禁止名单。进一步看：

### 反射拒绝美学车道

与字体列表平行。目前审美家族已饱和，品牌表面已泛滥成灾。如果一个简报落在这些通道之一，而没有“需要”它的注册原因（一本真正的杂志，一个真正的终端，一个真正的工业标牌系统），那么这是二阶训练反射：比选择弗朗西斯字体更深一层的陷阱。进一步看。

- **社论印刷。** 显示衬线（通常是斜体）+小单色标签+直纹分隔符+单色限制。受克林姆影响，杂志封面的矫揉造作。到 2026 年，所有与 Stripe 和 Notion 相关的品牌都已登陆这里。指纹：三个按规则分隔的列，斜体 Fraunces / Recoleta / Newsreader 标题，小写轨道间隔元数据，无图像。

（更多条目以与字体列表更新相同的节奏登陆。粗野主义实用主义和酸极繁主义可能会在饱和时加入。当它们回落到饱和度以下时删除条目也很好。）

反射拒绝列表适用于**新设计选择**。当现有品牌已经将某种字体或泳道作为其标识的一部分时，标识保护就会获胜；现有表面上的变体不会事后猜测已经发货的产品。反射拒绝列表用于绿地决策和 [live.md](live.md) 中的出发模式变体。

### 配对和语音

特色+精致是目标。具体形状取决于品牌，而不是品牌的类别。类别（“餐厅”、“开发工具”、“杂志”、“金融科技”）不是菜谱；而是菜谱。将其视为一个整体是 SKILL.md 所警告的一阶反射。

至少两个家庭是*仅*当声音需要时的规则。一个精心挑选的、具有坚定的重量/尺寸对比的系列比胆怯的显示器+机身对更强。

### 规模

模块化刻度，标题为流体 `clamp()`，步之间比率 ≥1.25。扁平尺度（间隔 1.1 倍）读作未承诺。

深色背景上的浅色文本：将行高添加 0.05–0.1。轻型类型意味着重量较轻，需要更多的呼吸空间。

## 颜色

品牌表面允许使用“承诺”、“全调色板”和“浸透”策略。使用它们。单一饱和的颜色分布在英雄身上并不过分；这是声音。米色和柔和的石板色登陆页面会忽略寄存器。

- 在选择策略之前给出一个真实的参考。 “Klim Type Foundry #ff4500 橙色浸透”、“条纹紫白克制”、“液体死亡酸绿全调色板”、“Mailchimp 黄色全调色板”、“Condé Nast Traveler 静音海军蓝克制”、“Vercel 纯黑单色”。无名的野心变成米色。
- 调色板是声音。一个冷静的品牌和一个躁动的品牌不应该共享调色板机制。
- 当战略坚定或渗透时，颜色承载着品牌。不要用中性的边缘来对冲。犯罪。
- 不要跨项目趋同。每个品牌的表面都与上一个不同。
- 当文化符号调色板是明显的吸引力时，超越它。让文化解读来自排版、图像和文案，而不是调色板。

## 布局

- 不对称组合是一种选择。故意打破网格以强调重点。
- `clamp()` 的流体间距可在更大的视口上呼吸。节奏各不相同：大量的分离，紧密的分组。
- 对于以图像为主导的简报（酒店、餐厅、杂志、摄影），带有重叠菜单和居中标题的全屏英雄图像是一个规范的举动；让照片成为设计。
- 当卡片是正确的可供性时，请使用 `grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))` 实现无断点响应。

## 图像

品牌表面依赖于图像。没有任何图像的餐厅、酒店、杂志或产品登陆页面看起来不完整，不那么受限制。英雄图像所在的纯色矩形比代表性库存照片更糟糕。

**当简报暗示图像时，您必须提供图像。**零图像是一个错误，而不是设计选择。 “克制”不是借口。如果批准的作品或简介以图像为主导，则提供真实的项目资产、生成的光栅资产或可靠的画布/SVG/WebGL 场景。请勿使用通用 CSS 面板、装饰图、卡片、项目符号或副本替换摄影、建筑、产品或地点图像。

- **对于没有本地资源的绿地工作，请使用库存图像。** Unsplash 是默认设置。 URL 形状为 `https://images.unsplash.com/photo-{id}?auto=format&fit=crop&w=1600&q=80`. **Verify the URLs before referencing them.** If you have an image-search MCP, web-fetch tool, or browser access, use it to find real photo IDs and confirm they resolve. Guessed IDs (even ones that look real) often 404 and ship as broken-image placeholders. Without a verification path, pick fewer photos you're confident exist over more that you guessed; never substitute colored `<div>` 占位符。
- **搜索品牌的实物**，而不是通用类别：“在有划痕的木桌上手工制作的意大利面”胜过“意大利食品”； “黄昏时石灰石酒店外墙上的柏树”胜过“豪华酒店”。
- **一张决定性的照片击败五张平庸的照片。** 英雄形象应该体现一种情绪；添加更多库存并不能拯救犹豫不决的人。
- **替代文本是语音的一部分。** “沿海宽面条，手工切割，在露台上供应”胜过“面食”。

这里的“图像”比库存摄影更广泛：产品屏幕截图、自定义数据可视化、生成的 SVG 和画布/WebGL 场景都是图像。仅文本页面，仅排版就承担了全部视觉重量，这是失败模式。

## 运动

- 当品牌邀请时，精心策划的页面加载胜过分散的微交互。有些品牌完全跳过入口动作；克制就是声音。

## 品牌禁令（除了共享的绝对禁令之外）

- 等宽字体作为“技术/开发者”的懒惰简写。如果品牌不是技术性的，单声道就会被解读为服装。
- 每个标题上方都有大圆角图标。尖叫模板。
- 通过反射而不是声音选择家庭的单一家庭页面。 （特意选择的单身家庭就可以了。）
- 正文全部大写。保留短标签和标题的上限。
- 胆怯的调色板和平均的布局。安全=隐形。
- 简报中暗示图像的零图像（餐厅、酒店、食品、旅行、时尚、摄影、爱好者）。英雄照片所属的彩色块。
- 非杂志形状的内裤默认采用社论杂志美学（显示衬线 + 斜体 + 首字下沉 + 宽幅网格）。编辑是一种审美风格，而不是默认的品牌审美。
- 每个部分标题上方重复出现微小的大写跟踪标签。单一强力踢球可以是声音；重复它作为部分语法是人工智能脚手架，除非它是一个故意的、命名的品牌系统。

## 品牌权限

品牌可以提供产品无法提供的东西。带走他们。

- 雄心勃勃的首次加载动作。揭示和排版编排赢得了自己的位置；每个部分都不会在滚动时淡入淡出。
- 单一用途视口。每一页都有一个主导思想，长卷轴，从容的节奏。
- 意想不到的色彩策略。调色板是声音；冷静的品牌和躁动的品牌不应该共享调色板机制。
- 每个部分的艺术指导。如果叙述需要的话，不同的部分可以有不同的视觉世界。声音的一致性胜过治疗的一致性。
